# Accessibility rules (RGAA / WCAG 2.1 AA)

These are blocking in code review. Any change that violates them gets flagged.

## Links

- Every `<a>` must have a discernible, unique purpose.
- Repeated generic text ("Lire l'article", "En savoir plus", "Lire plus", "Voir plus") **must** carry an `aria-label` that names the destination:
  ```php
  aria-label="<?php echo esc_attr( 'Lire l\'article : ' . get_the_title() ); ?>"
  ```
- Image-only links must have `aria-label` on the `<a>` (not alt text on the `<img>`):
  ```php
  <a href="…" aria-label="<?php echo esc_attr( 'Lire l\'article : ' . get_the_title() ); ?>">
      <img src="…" alt="">
  </a>
  ```
- Every `href` value must be wrapped in `esc_url()`. Never use `the_permalink()` in an href — it echoes the URL inline and causes double output; use `esc_url( get_permalink() )` instead.
- `target="_blank"` always requires `rel="noopener noreferrer"`.

## Buttons

- Every `<button>` must have visible text **or** an `aria-label`. Icon-only buttons (`&times;`, Font Awesome icons) need:
  ```php
  aria-label="<?php esc_attr_e( 'Fermer', 'arnauneprim' ); ?>"
  ```

## Interactive elements

- Use `<a>` or `<button>` for interactive elements — never `<div onclick>`, `<span onclick>`, or `<li onclick>`. These are keyboard-inaccessible and fail WCAG 2.1.1.
- Tap targets must meet WCAG 2.5.5 (44×44 px minimum). Use `min-height: 48px` + `display: inline-flex` + `align-items: center` on CTA elements.

## Color contrast

- Text on white: minimum 4.5:1 (WCAG AA). Interactive elements: minimum 3:1 for non-text contrast.
- Theme color tokens are the single source of truth — fix contrast in `:root` CSS variables, not per-component.

## Images

- Decorative images: `alt=""`.
- Informative images: `alt` describes the image content in French.
- Never omit the `alt` attribute entirely.

## Language

All aria-labels, button labels, and screen-reader text must be in **French**.

## Audit skill

Run `/a11y-links-buttons` to grep all components for the six failure categories above and get a per-file report.
